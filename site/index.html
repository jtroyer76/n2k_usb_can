n2k_usb_can

Firmware that turns an M5Stack AtomS3 Lite on an ATOMIC CAN Base into a USB-to-CAN adapter. Linux sees it as a standard gs_usb (candleLight) device: it shows up as can0 with no drivers to install. Built for NMEA 2000 into Signal K. Version ….

Before you install: download mode

Once this firmware is running, the AtomS3 no longer shows up as a serial port, so the installer can't reach it on its own. Put it in download mode first; this is also how you'd reinstall later.

  1. Hold the AtomS3's side button and plug it into this computer by USB-C (or, already plugged in, hold the button about 2 seconds until the small green LED inside lights).
  2. Release the button. The AtomS3 now shows up as a serial port.
This browser can't install firmware. Use Chrome or Edge on a computer. Open this page over https to install.

Click Install and choose the AtomS3's serial port (often "USB JTAG/serial debug unit"). Erase the device on a first install. To reinstall a gateway you've set up, don't erase: its settings are kept. (Erasing is also how to start over if you've forgotten the device password.)

When it finishes, unplug the AtomS3 and plug it back in. It sometimes stays in download mode after installing until it's power-cycled. The installer may then say it can't connect to the device: that's expected, because it's now a CAN adapter, not a serial port.

After installing

Plug it into the Linux host (e.g. a Raspberry Pi). lsusb shows 1d50:606f and can0 appears. For NMEA 2000, bring it up at 250 kbit/s:

sudo ip link set can0 up type can bitrate 250000
candump can0

To bring it up at boot, and to connect Signal K, see the README. The LED: dim red = no USB host, blue = idle, green = bus OK (flashes on traffic), orange = bus errors, blinking red = bus-off.

WiFi setup (optional)

The CAN adapter works over USB without any of this. WiFi adds firmware updates without a cable and a stats page.

  1. Power the gateway. With no WiFi saved, it starts its own open WiFi, N2K-CAN-XXXX.
  2. Join it with your phone. The setup page usually opens by itself; if not, open http://192.168.4.1/setup.
  3. Choose the boat's WiFi network (names are case-sensitive) and enter its password. Note the device password shown on the page, or set your own: it's needed for updates and to change settings later.
  4. Save. The gateway restarts and joins the boat's network.

Then the stats page is at http://n2k-can-gw.local/ and settings at /setup. If the boat network is missing for 5 minutes, the gateway starts its own WiFi again, this time protected by the device password. Updates over WiFi use the -update.bin file from a release:

curl -H "X-OTA-Key: <device password>" --data-binary @n2k_usb_can-<version>-update.bin http://n2k-can-gw.local/update
